# Security Policy

## Supported Versions

Security fixes go to the latest version on the `main` branch only. Keep your deployment up to date.

## Reporting a Vulnerability

Please do not open a public issue. Report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository.

Include the affected version or commit, the steps to reproduce and the impact you expect. We will acknowledge the
report, keep you informed and credit you in the fix unless you prefer not to be named.

delitesco-core is a fork of [SimpleLogin](https://github.com/simple-login/app). Vulnerabilities that also affect
upstream SimpleLogin should be reported to them as well.
